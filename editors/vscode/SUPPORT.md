# SplitScript support

Report reproducible bugs and request features through the
[SplitScript issue tracker](https://github.com/LiveSplit/SplitScript/issues).

When reporting a compiler or language-server problem, include the smallest
`.split` source that reproduces it and the relevant output from VS Code's
**SplitScript Compiler** or **SplitScript Language Server** channel.

For debugger failures, also include the **Auto Splitting Runtime** output and
the operating system and VS Code version in use. Do not publish process-memory
contents or other sensitive game data in an issue.
